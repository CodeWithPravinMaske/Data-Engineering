# Iceberg

Apache Iceberg: an open table format for huge analytic tables.

## What to Learn

- Metadata layers: metadata.json → manifest list → manifests → data files
- Snapshots, time travel, rollback
- Hidden partitioning and partition evolution
- MERGE INTO, copy-on-write vs merge-on-read
- Catalogs: REST, Hive, Glue, Nessie, Polaris
- Maintenance: compaction, expire snapshots
