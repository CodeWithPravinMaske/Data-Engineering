# System Design

## What to Learn

- A framework: clarify requirements → estimate → high-level design → deep dive → trade-offs
- Common designs: URL shortener, rate limiter, news feed, chat
- Data-specific designs: clickstream analytics, CDC to a lakehouse, real-time dashboards
