# Spark

Apache Spark: distributed compute for batch, SQL, and streaming.

## What to Learn

- Architecture: driver, executors, DAG, stages, tasks
- RDD vs DataFrame vs Dataset; lazy evaluation
- Transformations (narrow vs wide), shuffles, partitions
- Joins: broadcast, sort-merge, skew handling
- Caching, AQE, and performance tuning
- Structured Streaming
