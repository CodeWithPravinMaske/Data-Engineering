## Animated Learning: [DSA Animator](https://dsaanimator.com)

Step-by-step animations of LeetCode-style problems, with the code highlighted line by line in **Java and Python** as the animation runs. It helps you *see* how a pattern works instead of only reading the code.

**Patterns covered:** Two Pointers · Sliding Window · Binary Search on Answer · Monotonic Stack · Fast & Slow Pointers · Multi-source BFS · Topological Sort · Dijkstra · Union-Find · Backtracking · Kadane · Prefix Sum · Heap (Top-K) · 1D & 2D DP · Trie · Merge Intervals

> Partly free: some problems and previews are always free; the rest needs a paid plan (new accounts get a short free trial).

### Suggested way to use it
1. Pick a pattern (start with Two Pointers → Sliding Window → Binary Search).
2. Watch the animation once, then solve the same problem yourself without looking.
3. Solve 2–3 more LeetCode problems that use the same pattern.
