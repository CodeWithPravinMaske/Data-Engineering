# SQL

SQL concepts, functions, joins, subqueries, optimization, and normalization.

## What to Learn

- SELECT, WHERE, GROUP BY, HAVING, ORDER BY, and the logical order of execution
- Joins (inner, left, right, full, self, cross) and set operations
- Subqueries and CTEs (including recursive CTEs)
- Window functions: ROW_NUMBER, RANK, DENSE_RANK, LAG/LEAD, running totals
- Normalization (1NF → BCNF), indexes, and reading query plans
