# dbt

dbt: SQL + Jinja transformations with testing and docs.

## What to Learn

- Models, ref(), source()
- Materializations: view, table, incremental, ephemeral
- Tests (generic and singular), snapshots (SCD Type 2)
- Macros and Jinja; packages (dbt-utils)
- Layering: staging → intermediate → marts
